git-cleanup v0.1.0

Zero-dependency CLI that scans local & remote Git branches, cross-references branch activity with PR merge status on GitHub, and safely prunes merged / orphaned / stale branches. This page is a live look at the project: commands, decision model, and two interactive demos that mirror the CLI's real logic.

Node ≥ 18 · no npm deps git only — never touches .git internals PR data via gh CLI or GITHUB_TOKEN 25 tests passing · CI on Node 18/20/22

01Commands

$ git-cleanup scan
# PRUNE / stale table for every branch,
# with age, merge state, PR status, reason
# --json  --check (exit 2 if dirty)  --verbose
$ git-cleanup prune
# deletes nothing without confirmation
# merged branches  -> git branch -d
# force rules      -> git branch -D
# --remote         -> git push --delete
$ git-cleanup prs
# stale open PRs (>30d no activity)
# --close closes them, with a comment
# opt-in twice: config + flag

03Safety model

VerdictMeaningNeeded to delete
PRUNE merged into a base branch & past the age threshold, or matched an explicit rule prune + confirmation
stale unmerged & untouched for a long time, or an abandoned PR never automatic — review in scan
kept protected, checked out, a base branch, an open PR, or too young —

Protected by default: main master develop dev release release/** staging qa trunk, base branches and HEAD. Unmerged work is never deleted unless it matches a mode:"any" force rule you wrote yourself. Merged = the branch tip is an ancestor of a base branch (origin/main etc.). Local deletes use -d (safe); only force rules use -D.

06Configuration

// .gitcleanup.json — found walking up from cwd, merged over
// ~/.config/git-cleanup/config.json, then built-in defaults.
{
  "protected": ["special/release", "vendor/**"],
  "deleteMergedAfterDays": 21,
  "warnUnmergedAfterDays": 45,
  "rules": [
    { "match": "feature/ci-*", "mode": "merged", "minAgeDays": 7 },
    { "match": "tmp/**", "mode": "any", "minAgeDays": 1 }
  ],
  "pr": {
    "track": true, "staleAfterDays": 30,
    "closeStaleAfterDays": 60
  },
  "remote": { "pruneMerged": true, "deleteAbandonedAfterDays": 0 },
  // Safety net: bundles refs before -D / remote deletions (default on); retainDays > 0 sweeps old ones
  "backup": { "enabled": true, "dir": null, "retainDays": 0 },
  "repos": ["../other-project"]
}

07Run it yourself

$ npm i -g @maliqkara/gitcleanup   # adds `git-cleanup` to PATH
$ cd ~/your/repo && git-cleanup scan
$ git-cleanup prune            # asks before deleting
$ npm test                     # unit + integration test suite
